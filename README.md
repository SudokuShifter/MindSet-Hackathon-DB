## Установка

```bash
uv sync --frozen
```

## Быстрый старт
1. **Создание нового файла миграции:**
   ```bash
   uv run --env-file=.env yoyo new -m "<название миграции>"
   ```

2. **Формат именования миграций:**

   ```
   V<major.minor>-<имя_миграции>
   ```

   - Создание/удаление таблицы или столбца → увеличиваем **мажорную** версию
   - Добавление комментариев, изменение значений по умолчанию → увеличиваем **минорную** версию

## Использование

### Создание миграций

```bash
uv run --env-file=.env yoyo new ./migrations -m "<имя миграции>"
```

### Применение миграций

Применить все неприменённые миграции:

```bash
uv run --env-file=.env yoyo apply
```

### Откат миграции

Откатить последнюю миграцию:

```bash
uv run --env-file=.env yoyo rollback
```
Откатить конкретную миграцию и все после нее:
```bash
uv run --env-file=.env yoyo rollback --revision <revision>
```
